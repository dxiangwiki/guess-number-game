# 碰运气小游戏（guess-number-game）

一个纯前端 HTML / JavaScript 的猜数字碰运气小游戏，无需后端，浏览器直接打开 `index.html` 即可游玩。

## 玩法规则

- 初始余额：**1000**（余额可以有小数）
- 投币金额必须是整数，范围：`1 ≤ 投币 ≤ 当前余额`，不能为 0 或小数
- 每局随机生成一个 **1 ~ 50** 的数字，支持两种猜测模式：
  - **精确猜数字**：猜中精确数值，返还 **60 倍**投币
  - **猜区间**：猜 `1~25` 或 `26~50`，猜中返还 **1.8 倍**投币
- 猜错不返还本金
- 点击开始后先扣除投币金额，倒计时 3 秒后公布结果
- **封存（冻结）**：可将当前余额的一部分转入独立的冻结账户，封存部分不再参与投币
- **取回（解冻）**：每累计赢满 **10 次**后，可从冻结账户取回金额转回余额；取回后获胜次数重新累计

## 功能特性

- 冻结账户：单独封存金额，实时展示封存余额与取回解锁进度（当前胜场 / 10）
- 战绩统计：最高单次盈利、最高单次亏损、累计总盈利、累计总亏损
- 对局历史：记录每局时间、模式、投币、开出数字、输赢与盈亏（最多保留 50 条）
- 余额、冻结金额、获胜计数、战绩、历史记录均通过 `localStorage` 持久化，刷新页面不丢失
- 支持独立重置：只重置余额 / 只清空战绩统计 / 只清空对局历史
- 白色清爽界面，已做移动端响应式适配

## 使用方式

直接在浏览器中打开 `index.html`，或使用 GitHub Pages 访问仓库中的页面。

## 技术栈

- HTML + CSS + 原生 JavaScript
- `localStorage` 本地存储
